# Enviar ao GitHub

Envie o conteúdo desta pasta à raiz do repositório canalmarketplace2026-s/sitecanal, branch main. Preserve o .gitignore e o .env.example. Não envie .env, node_modules, .next ou dados privados.

Esta pasta contém o código, as imagens e as integrações. As credenciais ficam somente no servidor. Enviar arquivos ao GitHub não comprova que o servidor publicou a mudança: confirme o repositório/branch do mecanismo de deploy e confira o site público.

O envio ao Git foi preparado; não se deve substituir o banco nem executar novamente o seed em uma atualização visual. Consulte DEPLOY.md.
