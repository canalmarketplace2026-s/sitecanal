# Conferências do responsável

- Fazer uma compra real e conferir cobrança no Asaas, atualização do pedido e recebimento no Tiny antes da divulgação. O assistente não movimentou dinheiro nem comprou etiquetas.
- Conferir a pendência de dados bancários ainda indicada pela API Asaas, apesar da aprovação geral.
- Confirmar com a hospedagem o vínculo do deploy automático ao repositório sitecanal/main e a recuperação dos processos após reinício completo do servidor.
- Produtos sem fotos, peso, medidas ou saldo devem ser completados no Tiny. Não há imagens ou estoque fictícios para preencher essas ausências.
- Para etiquetas, usar NF-e e dados fiscais válidos. A isenção de IE foi informada pelo usuário; a aceitação de cada transportadora será verificada no primeiro envio.
